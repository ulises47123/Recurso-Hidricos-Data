Manual del Proyecto de Recursos Hídricos

Guía paso a paso para la instalación, automatización de dependencias, ejecución en entorno local y configuración remota con GitHub. Diseñado para ser accesible, ordenado y directo.

Versión oficial de Python: Python 3.11.9 (64-bit / 32-bit)
Puerto por defecto: 8000 (HTTP/HTTPS)
1

Introducción al Proyecto

Alcance, arquitectura general y funcionamiento del sistema.

Bienvenido al Manual del Proyecto de Recursos Hídricos. Esta plataforma es una solución integral orientada a la gestión administrativa y operativa del personal y legajos de la Dirección Provincial de Recursos Hídricos (DPRH Jujuy).

Tras analizar la estructura de la aplicación, el sistema opera bajo una arquitectura modular y desacoplada compuesta por los siguientes componentes clave:

💻 Interfaz y Frontend

Construido con soporte para aplicación de escritorio mediante Electron y paneles web modernos para la carga ágil y consulta de legajos y documentación.

⚡ Backend Robusto (FastAPI)

Desarrollado en Python con el framework FastAPI, gestionando endpoints de alta velocidad, validaciones de esquemas y reglas de negocio en el puerto 8000.

🗄️ Persistencia de Datos

Almacenamiento estructurado mediante base de datos SQL (SQLite/PostgreSQL), encargada de la información de empleados, turnos y legajos digitales subidos.

🌐 Conectividad y Sincronización

Mecanismos de acceso seguro (túneles Cloudflare y certificados locales) y sincronización con GitHub para versionado de cambios y documentación.

ℹ️
Objetivo del manual: Asegurar que cualquier usuario, sin requerir experiencia previa avanzada en desarrollo, pueda desplegar y operar el sistema en su equipo de trabajo de forma exitosa.

Requisitos Previos e Instalación

Pasos detallados desde la preparación del entorno hasta la organización de carpetas.

Paso 1

Instalación y Verificación de Python

El sistema requiere Python 3.11.9 para ejecutar el servidor central y todos los módulos.

1. Descarga e Instalación de Python

Descargue el instalador oficial directo correspondiente a la arquitectura de su equipo:

📥 Descargar Python 3.11.9 (64-bit) 📥 Descargar Python 3.11.9 (32-bit)
⚠️
Paso obligatorio durante la instalación: En la primera pantalla del instalador de Python, active la casilla inferior "Add python.exe to PATH" (Agregar Python a las variables de entorno) antes de presionar "Install Now".

Referencia: Asegúrese de marcar la casilla "Add python.exe to PATH" tal como se indica arriba.

2. Comprobación de la Instalación mediante CMD

Una vez concluida la instalación, abra una ventana de comandos de Windows (presione las teclas Windows + R, escriba cmd y presione Enter) y ejecute el siguiente comando para verificar:

Consola de Comandos (CMD) 
python --version

Debe responder con Python 3.11.9. Si es así, su sistema ya está listo para el siguiente paso.

Paso 2

Descarga del Proyecto desde GitHub (.ZIP)

El código fuente y todos los archivos del sistema se encuentran alojados en el repositorio oficial de GitHub:

🔗 Repositorio: Recurso-Hidricos-Data

Instrucciones para descargar el archivo comprimido:

  1. Ingrese al enlace del repositorio en GitHub indicado arriba.
  2. Ubique el botón verde que dice "Code" (o "Código") situado en la parte superior derecha de la lista de archivos.
  3. Haga clic sobre él para desplegar el menú de opciones y seleccione "Download ZIP" (Descargar ZIP).
📌 Referencia visual en GitHub:
<> Code ▼ ➜ Clic en el botón verde desplegable.
📦 Download ZIP ➜ Clic para iniciar la descarga del archivo comprimido.
⚠️
Importante: Asegúrese de que la descarga de Recurso-Hidricos-Data-main.zip finalice al 100% antes de descomprimirlo para evitar archivos incompletos.
Paso 3

Creación de una Cuenta en GitHub

GitHub es el servicio en la nube donde se respaldará el código fuente y las configuraciones del proyecto. Si aún no cuenta con un usuario:

  1. Ingrese al sitio web oficial de GitHub: github.com.
  2. Haga clic en el botón "Sign up" ubicado en la esquina superior derecha.
  3. Ingrese su dirección de correo electrónico institucional o personal, defina una contraseña segura y elija un nombre de usuario.
  4. Resuelva la verificación de seguridad y confirme el código de validación enviado a su correo electrónico.
🌐 Crear Cuenta en GitHub (Gratis)
Paso 4

Ubicación y Descompresión en "Documentos"

Para mantener una ruta limpia y evitar inconvenientes con permisos restringidos de Windows, debe mover el archivo comprimido a su carpeta personal de Documentos:

  1. Copie o traslade el archivo .zip descargado desde la carpeta "Descargas" hacia la carpeta Documentos (C:\Usuarios\[Su_Usuario]\Documentos).
  2. Haga clic derecho sobre el archivo comprimido y seleccione "Extraer todo..." (o utilice su programa descompresor habitual como 7-Zip o WinRAR).
  3. Finalice la extracción en esa misma ubicación de Documentos.
Paso 5

Renombrar la Carpeta Resultante

Una vez extraídos los archivos, verifique el nombre de la carpeta contenedora. Debe renombrarla de forma exacta para que coincida con el estándar de trabajo del proyecto:

📁
Nombre exacto requerido: recursos hídricos
(En minúsculas, con tilde y espacio: "recursos hídricos")

Haga clic derecho sobre la carpeta descomprimida, elija Cambiar nombre (o presione la tecla F2), escriba recursos hídricos y presione Enter.

3

Ejecución y Configuración Inicial

Puesta en marcha automática mediante el script de inicio y gestión de privilegios.

Acción 1

Ejecución del Automatizador (.bat)

Ingrese a la carpeta recursos hídricos. Dentro encontrará un archivo por lotes con extensión .bat denominado iniciar_sistema.bat.

Para iniciar el sistema de manera correcta:

  1. Haga clic derecho sobre el archivo iniciar_sistema.bat.
  2. En el menú desplegable, seleccione estrictamente la opción "Ejecutar como administrador".
🛡️
¿Por qué como administrador? El script configura automáticamente las reglas del Firewall de Windows para el puerto 8000 y habilita las resoluciones de dominio local necesarias para el entorno sin requerir configuración manual.
Acción 2

Confirmación en la Ventana Emergente de Windows (UAC)

Inmediatamente después de ejecutar el archivo, el sistema operativo Windows mostrará la ventana emergente de Control de Cuentas de Usuario (UAC) preguntando: "¿Quieres permitir que esta aplicación haga cambios en el dispositivo?".

✔️
Debe hacer clic en el botón "Sí" para otorgar los permisos y permitir que el instalador continúe su secuencia sin interrupciones.
Acción 3

Descarga Automática de Recursos y Apertura del Sistema

Al autorizar la ejecución, se abrirá una consola donde el script llevará a cabo automáticamente los siguientes pasos técnicos:

  • Creación del entorno virtual (venv): Genera un entorno aislado de Python para evitar conflictos con otras aplicaciones de su equipo.
  • Descarga e instalación de dependencias: Lee el archivo requirements.txt e instala automáticamente FastAPI, Uvicorn y demás librerías requeridas.
  • Habilitación de red: Añade la regla en el Firewall de Windows para el puerto TCP 8000.
  • Inicio del servidor y panel: Lanza el servidor backend y el panel de control gráfico de escritorio.

Una vez concluido este proceso, el sistema estará operativo localmente. Podrá acceder a la interfaz mediante su navegador web en las siguientes direcciones:

Ámbito de Acceso URL de Acceso Descripción
Local (este equipo) https://localhost:8000 Acceso directo desde la misma computadora donde corre el servidor.
Red Institucional / LAN https://recursoshidricos.local:8000 Acceso mediante el nombre de host configurado en la red local.
💡
Nota: En las ejecuciones posteriores, el script detectará que las librerías ya están instaladas y abrirá el sistema inmediatamente en cuestión de segundos.
4

Creación y Vinculación con GitHub

Paso a paso para crear el repositorio público y sincronizarlo sin tocar la consola.

Crear el Repositorio en GitHub (Debe ser Público)

Para tener el repositorio en su cuenta o publicar el portal institucional en GitHub Pages:

  1. Iniciar sesión: Ingrese a github.com/login con su cuenta.
  2. Nuevo repositorio: Haga clic en el botón "+" arriba a la derecha y seleccione "New repository" (o ingrese a github.com/new).
  3. Nombre del repositorio: En "Repository name" coloque el nombre deseado (por ejemplo: Recurso-Hidricos-Data).
  4. Visibilidad (OBLIGATORIO PÚBLICO): Seleccione Public (Público). Es necesario para el despliegue de GitHub Pages y el acceso a la web.
  5. Opciones de inicialización: ¡NO marque casillas adicionales! Deje desmarcadas "Add a README file", ".gitignore" y "Choose a license".
  6. Crear: Presione el botón verde "Create repository".
📌 Casillas a verificar en GitHub:
✅ Repository name: Nombre asignado.
✅ Visibilidad: 🔘 Public (Público seleccionado).
❌ Add a README file: Desmarcado.
ℹ️
Sincronización automática: Una vez creado el repositorio, el programa se encarga de conectar la carpeta local y sincronizar el contenido desde la interfaz gráfica (pestaña "GitHub & Portal"), sin necesidad de abrir la terminal ni escribir comandos Git.
