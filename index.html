Manual de Instalación y Operación del Sistema

Guía paso a paso ilustrada con capturas de pantalla para configurar el entorno, iniciar el servidor central y gestionar la sincronización automática con GitHub.

Versión oficial de Python: Python 3.11.9 (64-bit / 32-bit)
Puerto de red: 8000 (HTTPS Local y LAN)
Acceso: Panel Ligero Tkinter + Navegador Web
1

Requisitos Previos: Instalación y Verificación de Python

El único requisito previo obligatorio que debe instalar en su equipo Windows.

El sistema funciona sobre el lenguaje de programación Python versión 3.11.9. Antes de iniciar por primera vez, descargue e instale el paquete correspondiente a su arquitectura:

📥 Descargar Python 3.11.9 (64-bit - Recomendado) 📥 Descargar Python 3.11.9 (32-bit)
⚠️
Punto crítico durante la instalación: En la primera ventana del instalador oficial de Python, marque obligatoriamente la casilla inferior: "Add python.exe to PATH" antes de presionar el botón "Install Now".

Referencia de instalación: Active la casilla "Add python.exe to PATH" en la parte inferior para que el sistema reconozca Python automáticamente.

Comprobación opcional de la instalación

Si desea comprobar que quedó correctamente instalado, presione las teclas Windows + R, escriba cmd, presione Enter y ejecute: python --version. Debe devolver Python 3.11.9.

2

Ubicación y Descarga del Proyecto

Dónde obtener los archivos y recomendaciones para la carpeta de trabajo.

Puede descargar el archivo comprimido del proyecto desde GitHub o utilizar la carpeta provista:

📦 Ir al Repositorio de GitHub: Recurso-Hidricos-Data
  1. En la página de GitHub, haga clic en el botón verde "<> Code" y seleccione "Download ZIP".
  2. Descomprima la carpeta en su disco local. Recomendación: Ubique la carpeta en una ruta sencilla como el Escritorio o C:\proyectos\recursos-hidricos (evitando rutas con caracteres especiales o acentos que puedan generar bloqueos).
3

Primer Arranque: Ejecutar como Administrador y Firewall

Flujo de inicio desatendido y autorización de red en Windows Defender.

Para poner en marcha el sistema central:

  1. Abra la carpeta del proyecto.
  2. Haga clic derecho sobre el archivo iniciar_sistema.bat.
  3. Seleccione estrictamente la opción "Ejecutar como administrador". Esto es necesario para habilitar los puertos en el Firewall y crear el entorno de ejecución sin trabas.
  4. Si Windows muestra el aviso de Control de Cuentas de Usuario (UAC), presione "Sí".
ℹ️
¿Qué ocurre en la primera ejecución? Se abrirá una ventana de consola que descarga e instala automáticamente las dependencias en un entorno aislado (venv). No cierre la ventana de consola; este proceso tarda sólo un momento y luego iniciará la aplicación de forma autónoma.

Autorización del Firewall de Windows (Paso Obligatorio)

Al iniciarse por primera vez el componente de túnel y red (cloudflared-windows-amd64.exe), Windows Defender Firewall mostrará una ventana emergente de seguridad:

Alerta de Seguridad de Windows Defender: En esta ventana debe marcar todas las casillas disponibles (especialmente "Redes privadas" y "Redes públicas" si aplica) y hacer clic en el botón "Permitir acceso" para que el servidor pueda comunicarse por la red.

4

Panel de Control: Servidor Central DPRH

Administración gráfica de conexiones de red, túnel de internet y acceso directo al sistema.

Una vez completado el inicio, se abrirá la ventana principal de la aplicación: "Gestión de Personal - Servidor Central DPRH".

Pestaña: Red & Acceso Remoto

Esta pantalla le brinda acceso inmediato al software sin necesidad de configurar nada manualmente:

  • Botón superior "ABRIR SISTEMA EN EL NAVEGADOR WEB": Abre la plataforma institucional directamente en su navegador predeterminado.
  • Direcciones de Conexión Local (LAN): Enlaces seguros para que otras computadoras de la oficina conecten por la red interna (ej. https://recursoshidricos.local:8000).
  • Acceso Remoto por Internet (Cloudflare): Muestra si el túnel está activo, el enlace remoto asignado y los botones "Iniciar Túnel", "Detener Túnel" y "Copiar URL Remota".

Referencia ilustrativa del Panel: Así se visualiza el estado del servidor activo en el puerto 8000, los enlaces de red local y la dirección de acceso por Internet generada por el túnel.

5

Vinculación con GitHub: Repositorio Propio y Llaves Públicas

Cómo desvincular el repo de ejemplo, registrar su nuevo repositorio y configurar la Deploy Key.

📌
¡Atención con el Repositorio! En la pestaña "GitHub & Portal" vendrá precargada la URL de un repositorio de ejemplo o previo. Usted debe borrarlo, colocar el enlace de su propio repositorio creado y generar una nueva llave pública SSH utilizando los botones que provee la aplicación.

1. Crear su Repositorio en GitHub y obtener el Enlace

  1. Ingrese a su cuenta en github.com/new.
  2. Asigne un nombre a su repositorio y seleccione obligatoriamente Public (Público). No marque README ni plantillas.
  3. Una vez creado el repositorio, haga clic en el botón verde "<> Code", asegúrese de estar en la pestaña HTTPS y copie el enlace provisto:

Ejemplo ilustrativo de GitHub: Al presionar "<> Code" se despliega el menú con la URL HTTPS de su nuevo repositorio. Copie ese enlace con el botón lateral.

2. Pegar la URL y Generar Nueva Llave en el Panel DPRH

Regrese a la aplicación en su computadora y seleccione la pestaña "GitHub & Portal":

  1. En el campo "URL del Repositorio GitHub", reemplace la dirección anterior pegando la URL de su nuevo repositorio y pulse "Guardar URL".
  2. Haga clic en el botón naranja "Restablecer / Generar Nueva Llave" para crear un par de llaves SSH limpias y exclusivas para su equipo.
  3. Haga clic en el botón "Copiar Llave Pública" para tenerla lista en el portapapeles.

Pestaña GitHub & Portal del Panel: Muestra el campo para ingresar la URL del repositorio, el botón naranja para generar la nueva llave pública y el botón para copiarla.

3. Agregar la Llave Pública (Deploy Key) en GitHub

Para que el software tenga autorización de sincronizar con su repositorio en GitHub:

  1. Vaya a su repositorio en la web de GitHub y haga clic en la pestaña "Settings" (Configuración) arriba a la derecha.
  2. En el menú lateral izquierdo, baje hasta la sección Security and quality y haga clic en "Deploy keys":

Menú de Configuración de GitHub: Ubique la opción "Deploy keys" resaltada en el lateral izquierdo.

  1. En la pantalla de Deploy keys, presione el botón azul "Add deploy key":

Pantalla de Deploy keys: Presione el botón superior derecho "Add deploy key" para registrar una nueva autorización.

  1. En el formulario que aparece:
    • En Title escriba un nombre identificador (por ejemplo: Servidor DPRH).
    • En Key pegue el texto de la llave que copió desde el panel.
    • PASO CRÍTICO: Marque obligatoriamente la casilla "Allow write access" (Permitir acceso de escritura).
    • Haga clic en el botón azul "Add key" para guardar.

Formulario de Deploy Key en GitHub: Pegue la llave pública y asegúrese de que la casilla "Allow write access" quede activada antes de pulsar "Add key".

4. Verificación y Sincronización Inmediata

Una vez agregada la llave en GitHub:

  1. En el panel DPRH, presione el botón "Probar Conexión con GitHub". El indicador cambiará a "• Señal Verde: Conexión establecida con éxito.".
  2. Presione el botón "Forzar Sincronización Inmediata a GitHub Pages" para subir la web del portal de manera 100% automática y sin escribir una sola línea de comandos en la terminal.

Conexión en Red Local (LAN) para Otras Computadoras

Cómo permitir que los equipos de la oficina accedan al sistema de forma directa.

Para que las demás computadoras conectadas a la misma red de la oficina puedan ingresar al sistema, existen 2 opciones muy sencillas. En Recursos Hídricos las direcciones IP suelen estar configuradas de manera estática/fija (por ejemplo: https://192.168.100.38:8000 o a través del dominio https://recursoshidricos.local:8000):

🌐 Opción 1: Acceso Directo en el Navegador del Cliente

En cualquier otra computadora de la misma red, puede crear un acceso directo en el escritorio para que el usuario ingrese con un solo clic:

  1. Haga clic derecho en el Escritorio de la PC cliente > Nuevo > Acceso directo.
  2. En la casilla de ubicación, escriba la dirección con la IP estática del servidor (ejemplo: https://192.168.100.38:8000 o https://recursoshidricos.local:8000).
  3. Haga clic en Siguiente, asígnele el nombre "Sistema Recursos Hídricos" y presione Finalizar.
  4. Al abrirlo, se iniciará el navegador web cargando inmediatamente el sistema.

⚡ Opción 2: Archivo ejecutable .BAT en la PC Cliente

Puede generar un archivo lanzador rápido para las máquinas clientes que abra automáticamente su navegador predeterminado:

  1. Cree un archivo de texto con el Bloc de notas llamado Abrir_Recursos_Hidricos.bat.
  2. Copie y pegue adentro la siguiente línea con la IP fija del servidor:
start https://192.168.100.38:8000

(O use start https://recursoshidricos.local:8000 según la configuración de la red).

💡
Nota de certificados en la red interna: La primera vez que una máquina cliente ingrese por https://, el navegador puede mostrar un aviso de certificado autofirmado local. Solo deben presionar "Configuración avanzada" y luego "Continuar a 192.168.100.38 (sitio no seguro)". Esto es completamente normal en redes internas protegidas por HTTPS local.

Checklist Resumida de Puesta en Marcha

Repaso rápido de los pasos para confirmar que el sistema quedó operativo.

  • ✅ 1. Python instalado: Python 3.11.9 instalado marcando la casilla "Add python.exe to PATH".
  • ✅ 2. Ejecutar como Administrador: Clic derecho sobre iniciar_sistema.bat > "Ejecutar como administrador".
  • ✅ 3. Firewall aceptado: En la ventana de Windows Defender, marcar las casillas y pulsar "Permitir acceso".
  • ✅ 4. Repositorio configurado: Crear nuevo repo en GitHub (Público), copiar enlace desde "<> Code" y pegarlo en el panel.
  • ✅ 5. Llave pública vinculada: Generar nueva llave en el panel, pegarla en Settings > Deploy keys de GitHub con "Allow write access" marcado.
  • ✅ 6. Sistema en funcionamiento: Probar conexión en verde y presionar "ABRIR SISTEMA EN EL NAVEGADOR WEB".
