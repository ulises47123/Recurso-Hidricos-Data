Instructivo de Uso y Arquitectura Técnica

1. Motor Python & SQLite: Todos los datos se gestionan a través de una API REST protegida y una base de datos relacional local que garantiza integridad referencial y auditoría total.

2. Aplicación de Escritorio Electron: Proporciona una interfaz gráfica nativa sin requerir conexión externa ni CDNs en internet.

3. Gestión de Licencias: El módulo valida automáticamente el tipo de personal (Planta Permanente vs Contratados) y permite a los auditores justificar u observar certificados.

4. Exportación Excel: Desde la sección "6. Exportar Excel" puede descargar el libro consolidado con todas las hojas: nómina, licencias, contratos y organigrama.
